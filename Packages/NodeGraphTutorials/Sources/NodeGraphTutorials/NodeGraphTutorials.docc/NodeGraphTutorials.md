# ``NodeGraphTutorials``

Learn to build, run and extend node graphs.

## Overview

NodeGraph is a general-purpose node graph system for macOS and iPadOS. These tutorials start from an empty graph and end with your own node pack, shipped as a Swift package.

The tutorials are being written one chapter at a time. Chapters planned:

- Build a graph with the Core package
- Show it in a SwiftUI editor
- Write a node pack
- Robotics and video walkthroughs
- Assistant and headless automation

For the system's design, read the NodeGraphCore documentation.
